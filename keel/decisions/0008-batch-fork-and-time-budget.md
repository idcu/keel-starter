# 0008 把 lint 的 per-file fork 批量化，并给 lint 自身设时限预算

## 背景

评估报告实测发现：`keel-lint.sh` 在 24 个热区文档的规模上要 **319 秒**。

根因**不是检查逻辑复杂，而是进程创建成本**：单次 fork 在 Windows/Git Bash
约 370ms（实测：20 次 `awk` 子进程 = 7.4s），而原实现有约 1500 次 per-file fork
——每文件各调 `wc`×2、`awk`、`grep`、`sed`、`basename`、`cd` 等。

这个数字对 Keel 是致命的，因为设计目标明写"长到 1GB 加载量恒定"：
24 文件就 5 分钟，500 文件就是 2 小时。**不可增长的检查等于没有检查。**

同时它违反了 Keel 自己的原则：§7 把"单次会话加载 ≤5k token"管到字节级，
却对**工具自身的执行时间零约束**——这是"机器验"唯一没覆盖到的地方。

## 决定

1. **批量化**：文件清单先落成 NUL 分隔清单，用 `xargs -0` 整体喂给
   `wc` / `awk`，把 N 次 per-file 调用换成 1 次。
   实测预算段 16.1s → 0.52s（31×）。
2. **frontmatter 一次提取**：一个 awk 抽出所有文件的全部 fm 字段落查询表，
   替代 `fm_val` 的 4 fork/次；再进一步改成纯 shell 内存查表（零 fork）。
3. **链接提取共用**：段 6（引用环）/ 8（死链）/ 9（孤儿）原本各自跑
   `grep+sed+tr`，段 9 还要为**每条链接** fork 2 次 `cd`（该段单独占 49 秒）。
   改为一次 awk 产物三段共用，路径规范化改成纯字符串运算。
4. **`LINT_SECONDS` 进 `budget.env`**，lint 自报耗时、超时告警——
   让"lint 变慢"也能被机器发现，而不只靠人记得测。

结果：**319s → 97s（降 70%）**，0 fail 与 24 个文档的检查结论完全不变。

## 被否掉的选项

| 选项 | 为什么没选 |
|---|---|
| 保持原样，靠"Linux CI 上够快"交代 | Keel 承诺的是"任何机器上都能跑"；本地 5 分钟等于劝退。fork 在 Linux 便宜 100× 不构成理由——用户不会只跑 CI |
| 全文重写为 Python 实现 | 违背 §9.3「内核零依赖」（无 python3 的机器上 lint 直接不可用）。自测已依赖 python3，**内核不能再加一条** |
| 引入并行（`xargs -P`） | 治标不治本：进程数没减少，只是同时跑。而且 Windows/Git Bash 的并行收益与 POSIX 差异大，引入不可移植行为 |
| 把 frontmatter 缓存成文件跨会话复用 | 缓存失效比不缓存更危险（改了文档但缓存没更新 → 判死失效）。**检查必须每次真读源文件** |
| 只在文档里记"性能靠平台保证" | 那是把问题写进文档而不是解决它，且违反 §2 原则 4：不能脚本化就不该承诺 |

## 后果

- **好处**：本地可用性从"5 分钟"变成"1.5 分钟"；规模上限从"几十个文件"
  放宽到"几百个文件"；且 `LINT_SECONDS` 让性能退化变成可告警事件。
- **代价 1（永久）**：脚本复杂度上升。可读性换性能是这个工具的第一次重大妥协——
  承认它，并写进本 ADR：段 6/8/9 现在**共享** `LINKS` 中间产物，
  改动链接提取逻辑必须同时看三段。
- **代价 2（永久）**：新增一类失效模式。本轮三次踩坑都不是逻辑写错，
  而是"该失败时没失败"（`xargs` 参数当文件名、`$(printf "\n")` 死循环、
  `wc` 汇总行被当文件）——**已全部登记进 `pitfalls/meta/`**。
- **自证方式**：`keel-lint.sh` 0 fail + 38 例自测（含新增的性能回归护栏）+ CI。

## 蒸馏（§7.4）

三条坑的共性不是 shell 用法，而是**一类判定标准**：

> 任何"优化"都会引入新的失效模式。
> 判据是——**原实现失败会报错，优化后失败是否仍会报错？**

这一条已具备上提资格（同类坑已 3 次）。但本轮 `triggers` 由钩子自动 +1、
尚未累积到阈值，故**先记在此处**，待 `triggers ≥ DISTILL_AT` 后
由 §7.4 流程正式上提为 `CONSTITUTION.md` 硬约束——不由本轮手工提前上提。
